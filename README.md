# ЦАИУ — Telegram-бот приёмной комиссии

Бот отвечает на вопросы абитуриентов на русском, казахском и английском языках. Ищет ответы на сайте университета через систему умного поиска (RAG).

---

## Структура проекта

```
.
├── bot/                    ← Telegram-бот (единственный файл)
│   └── run.py
│
├── rag_service/            ← Сервис поиска по базе знаний
│   ├── run_api.py          ← Запуск сервиса
│   ├── app/
│   │   ├── parser/         ← Скачивание и обработка страниц сайта
│   │   ├── indexer/        ← Сохранение в базу данных
│   │   └── retrieval/      ← Поиск по запросу пользователя
│   └── docker-compose.yml  ← База данных (Qdrant)
│
├── tools/                  ← Утилиты для IT-отдела
│   ├── reindex.py          ← Переиндексировать сайт
│   ├── check_chunks.py     ← Посмотреть что в базе
│   └── debug_search.py     ← Проверить поиск по запросу
│
├── requirements.txt        ← Зависимости Python
└── docker-compose.yml      ← База данных
```

## Первый запуск (один раз)

### Шаг 1 — Установить зависимости

```bash
pip install -r requirements.txt
```

### Шаг 2 — Создать файл конфигурации

```bash
cp .env.example .env
```

Открыть `.env` и заполнить:

| Параметр | Где взять |
|---|---|
| `OPENAI_API_KEY` | https://platform.openai.com/api-keys |
| `BOT_TOKEN` | @BotFather в Telegram |
| `API_SECRET_KEY` | Придумайте любую строку (16+ символов) |
| `RAG_API_KEY` | То же значение что и `API_SECRET_KEY` |

Остальные параметры менять не нужно.

### Шаг 3 — Запустить базу данных

```bash
docker-compose up -d
```

Проверить что работает:
```bash
docker ps
# Должны видеть: qdrant/qdrant
```

### Шаг 4 — Проиндексировать сайт (занимает 30–60 минут)

```bash
cd rag_service
python -m app.parser
```

Что происходит: система скачивает все страницы сайта caiu.edu.kz, разбивает на фрагменты, для каждого фрагмента генерирует вопросы через GPT и сохраняет в базу данных.

Стоимость первой индексации: ~$0.20–0.30 (оплачивается из баланса OpenAI).

Пример вывода:
```

  -> Title: История университета
  -> Chunks: 4  |  Questions: 16
```

## Ежедневная работа

### Запустить всё

Открыть 2 терминала:

**Терминал 1 — сервис поиска:**
```bash
cd rag_service

```

**Терминал 2 — бот:**


В каждом терминале нажать `Ctrl+C`.

## Предпросмотр перед индексацией

Перед запуском индексации можно посмотреть что именно будет обработано.

### Список всех URL которые будут проиндексированы

```bash
python tools/preview_urls.py
```

Показывает каждый URL со статусом:
- `[НОВЫЙ]` — страница будет проиндексирована впервые
- `[В БАЗЕ]` — уже проиндексирована, без изменений → пропустится
- `[ИСКЛЮЧЁН]` — фильтр блокирует этот URL (например `/news/`, `/kz/`)

### Проверить конкретный URL

```bash
python tools/preview_urls.py https://caiu.edu.kz/history-of-the-university-ru/
```

Показывает подробно:
- Проходит ли URL через фильтры
- Есть ли он в sitemap
- Есть ли он уже в базе (сколько чанков и вопросов)
- Скачивает страницу и показывает сколько фрагментов получится и как они выглядят

Работает даже если база Qdrant не запущена — в этом случае статус в базе не проверяется.

## Обновление базы знаний

Когда на сайте обновилась информация — нужно переиндексировать:

```bash
python tools/reindex.py
```

Система автоматически пропустит страницы которые не изменились и обновит только новые.

## Проверка и отладка

### Посмотреть все проиндексированные страницы

```bash
python tools/inspect.py
```

Выводит список всех страниц с количеством фрагментов и вопросов для каждой.

### Посмотреть содержимое конкретной страницы

```bash
python tools/inspect.py https://caiu.edu.kz/history-of-the-university-ru/
```

Выводит все фрагменты текста и сгенерированные вопросы для этого URL. Полезно чтобы понять почему бот не находит информацию — можно увидеть как именно разбита страница.

```bash
# Только фрагменты без вопросов:
python tools/inspect.py https://caiu.edu.kz/history-of-the-university-ru/ --no-questions
```

### Проверить поиск по конкретному вопросу

```bash
python tools/debug_search.py "сколько корпусов у университета"
```

Выводит какие фрагменты нашла система и с каким рейтингом релевантности.

### Очистить базу и начать с нуля

Нужно если изменили настройки индексации (размер фрагментов, структура чанков):

```bash
python tools/clear_index.py
# После очистки запустить заново:
python tools/reindex.py
```

### Проверить что RAG-сервис работает

```bash
curl http://localhost:8001/health
# Ответ: {"status": "ok"}
```

## Как это работает (кратко)

```
Пользователь пишет вопрос в Telegram
        ↓
Бот переводит на русский (если вопрос на казахском или английском)
        ↓
Сервис поиска ищет похожие фрагменты сайта в базе данных
        ↓
GPT формулирует ответ на языке пользователя
        ↓
Пользователь получает ответ
```

Зелёный индикатор 🟢 — ответ основан на информации с сайта.
Красный индикатор 🔴 — сервис поиска недоступен, GPT отвечает без базы.

## Частые вопросы

**Бот не отвечает на вопросы об истории / корпусах / конкретных темах?**
Переиндексируйте сайт: `python tools/reindex.py`

**Ошибка "Connection refused" при запуске?**
База данных не запущена. Выполните: `docker-compose up -d`

**Сколько стоит работа бота?**
Каждый вопрос пользователя стоит ~$0.001. 10 000 вопросов = ~$10.

**Нужно добавить информацию которой нет на сайте?**
Добавьте документ Google Docs — укажите его ID в `.env` (параметр `GOOGLE_DOC_ID`), затем переиндексируйте.
